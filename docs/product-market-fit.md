## Build for Yourself: The Acid Test

Will uses D1 (Cyon personality) as his daily driver.
If Will stops using it after 2 weeks, the product is wrong.
If Will is still using it at 3 months, the product is right.

The scroll counter is the metric.
- Week 1: scroll 15 (novelty)
- Week 4: scroll 40+ (habit forming)
- Month 3: scroll 100+ (can't live without)
- Month 6: scroll 300+ (it knows you)

If the scroll count plateaus before 50, the droid doesn't hold attention.
If it keeps climbing past 100, the droid is a companion, not a gadget.
